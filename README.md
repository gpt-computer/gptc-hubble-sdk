## Install

```shell
pip install gptc-hubble-sdk
```

```shell
conda install gptc-hubble-sdk -c conda-forge
```

Or with [uv](https://github.com/astral-sh/uv):

```shell
uv pip install gptc-hubble-sdk
```

## Core functionality

* Python API and CLI.
* Authentication and token management.
* Artifact management.
